# 🌰 `AcornFolio`

### `AI MUTUAL-FUND CO-PILOT`
**Next.js · TypeScript · Tailwind · Prisma · SQLite · LanceDB · RAG**

> Mutual-fund decisions involve numbers that shouldn't be left to guesswork.

AcornFolio helps users reason about **Direct vs Regular plans, SIP/SWP/STP, XIRR, tax, exit load, and portfolio overlap** — with a portfolio-aware AI assistant grounded in real fund data.

**The one decision that mattered: don't ask the LLM to do the maths.** Financial calculations stay deterministic, in code. The AI layer handles language and retrieval only.

# ⚡ `CodeFusion`

### `REAL-TIME COLLABORATIVE CODE EDITOR`
**React 18 · Node.js · Socket.io · Monaco Editor**

Started with one question: what if multiple people could code together in real time, with no perceptible lag? The editor itself wasn't the hard part — Monaco (the same engine behind VS Code) handles syntax highlighting and language support out of the box. The real problem was **synchronisation**: getting one user's keystroke to every connected client fast enough that it feels shared, not delayed. Built for pair-programming sessions and live interview practice — the version of screen-sharing you actually want.

<sub>🇩🇪 *Zusammen programmieren.* (Code together.)</sub>
