### `AI MUTUAL-FUND CO-PILOT`

**Next.js · TypeScript · Tailwind · Prisma · SQLite · LanceDB · RAG**

AcornFolio is a project where **software engineering, finance and AI** come together.

The idea started with a practical problem:

> **Mutual-fund decisions involve numbers that shouldn't be left to guesswork.**

AcornFolio helps users reason about:

- Direct vs Regular mutual-fund plans
- SIP / SWP / STP
- XIRR
- Tax considerations
- Exit load
- Portfolio overlap
- Fund information and comparisons
