## 👋 About

I'm a final-year CS student at JECRC University, Jaipur (class of 2027). I started with C and C++, fell properly into DSA and competitive programming, and then got curious about what sits *behind* an AI app: how information is represented, retrieved and grounded. That curiosity is what the Python and RAG work is about.

I learn by building. A tutorial tells me what something does; a project makes me understand why it works; debugging shows me where it breaks.

> **I don't want to just use technology. I want to understand enough to build with it.**

```text
question → learn → build → break → debug → understand → build better
```
